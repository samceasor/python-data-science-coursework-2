# Python Data Science Coursework 2 — Kampala Rainfall Prediction

## Project
Predicting whether rainfall will occur on a given day in Kampala using weather variables.

## Run
1. Install Python 3.11+.
2. Open a terminal in this project folder.
3. Run `pip install -r requirements.txt`.
4. Run `python collect_data.py`.
5. Run `python src/analysis.py`.

The collection script saves the raw API response as:
`data/kampala_weather_raw.csv`

The analysis script saves prepared data, metrics, reproducibility information and plots under:
`outputs/`

## Important submission evidence
